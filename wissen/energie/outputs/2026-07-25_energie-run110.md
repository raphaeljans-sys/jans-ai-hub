# Energie-Training — Run 110 (2026-07-25)

## Ausgangslage
PDF-Inventar seit Run 65 vollständig abgearbeitet. Run 105-109 hatten fünf Läufe in Folge bewusst
auf neue Themenwahl verzichtet (Sättigungsdiagnose, `wiki/QUESTIONS.md`). Run 109 hatte einen

## Was gemacht wurde
Kandidat gewählt: Swissolar «Batteriemonitor Schweiz 2026» (44 Seiten, publiziert März 2026), seit
Run 12 im Destillat `batteriespeicher-heimspeicher-pv-ch` als «PDF bildbasiert, Textextraktion
zweimal gescheitert» dokumentiert. Direkter Download unter der im Destillat bereits vermerkten
zweiten URL (`swissolar.ch/02_markt-politik/batteriesmonitor/sws_batteriemonitor_2026.pdf`) lieferte
eine echte PDF-Datei (7 MB, InDesign-Export) — die zuvor vermerkte HTML-Notiz betraf einen falschen
Pfad. Per Read-Tool (PDF-Modus, seitenweise) vollständig gelesen.

**Ergebnis:** Der Bericht enthält weit mehr als die bereits bekannte Preiszahl:

1. **Preiskurve primärquellenbestätigt:** 15-kWh-Heimspeicher 2022 CHF 827/kWh → 2023 846 → 2024
   708 → **2025 586 CHF/kWh** (CHF 8'850 installiert). Vorher nur Sekundärzitat, jetzt direkt aus
   der BFE-Preisbeobachtungsstudie 2024 + Swissolar-Mitgliederumfrage (n=117) zitiert.
2. **Vier bisher unbekannte Rechtsänderungen seit 1.1.2026**, keine davon vorher in der KB:
   - Netznutzungsentgelt-Rückerstattung für Speicher mit Endverbrauch (Art. 18d-i StromVV/
     Art. 14a Abs. 4 StromVG) — korrigiert die bisherige Benachteiligung ggü. Pumpspeicherwerken.
   - Einspeiselimitierung durch VNB, max. 3 % Jahresverlust (StromVG Art. 17c/StromVV Art. 19c),
     VSE-Praxis 70 % DC-Leistung — macht den Batteriespeicher wirtschaftlich attraktiver, weil nur
     die Netzeinspeisung betroffen ist, nicht die Speicherung dahinter.
   - RPG-Bewilligungspflicht für freistehende Batteriespeicher ausserhalb von Gebäuden geklärt
     (Art. 22/24 RPG) — beantwortet direkt eine bisher offene Bauherren-Frage.
   - Speicher-in-LEG-Messkonzept (Netznutzungsrabatt nur auf nachweislich lokal erzeugten/
     gespeicherten Strom, eigener Zähler bei Mischbetrieb).
3. **Förderlücke geschlossen:** keine nationale Förderung für Wohn-/Gewerbe-Speicher; Landwirtschaft
   (bis CHF 200/kWh) läuft Ende 2026 aus; Kt. Thurgau seit 1/2026, Schaffhausen, Neuenburg kantonal.
4. **Brandschutz-Zeitplan:** Totalrevision Brandschutzvorschriften (BSV 2026) mit voraussichtlich
   eigenem Teil zu Batteriespeichern, Vernehmlassung August 2026, Inkraftsetzung Herbst 2027.

## Werkzeug-Lehre bestätigt (zweiter Beleg in Folge)
Run 109 hatte die These aufgestellt: «WebFetch technisch gescheitert» ist keine dauerhafte
Sackgasse. Run 110 bestätigt das ein zweites Mal — auch ein als «bildbasiert nicht auslesbar»
dokumentiertes PDF liess sich mit derselben curl+Read-PDF-Methode vollständig lesen. Das deutet
darauf hin, dass das Read-Tool Bildseiten multimodal auswertet, wo reine Textextraktion (WebFetch,
pdftotext) versagt. Die Ausnahme dürften echte Bild-/JPEG2000-Scans sein (z.B. `denkmalschutz-
energiesanierung-zh-sz`), wo auch die Bildqualität selbst das Problem sein könnte — das ist der
nächste zu prüfende Grenzfall.
